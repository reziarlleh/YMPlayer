# YMPlayer

YMPlayer - неофициальный плеер Яндекс Музыки для Android 10+ с упором на
нормальное воспроизведение "Моей волны", оффлайн-кэш понравившихся треков и
работу на автомобильной магнитоле.

Проект вырос из эксперимента с интеграцией Poweramp, но теперь это отдельный
плеер с собственным MediaSession/MediaBrowser-сервисом. Android-система и
лаунчеры вроде CarWebGuru должны видеть YMPlayer как обычный медиаплеер.

Пакет приложения пока остаётся `dev.petrov.yaplay`, чтобы тестовые устройства
могли обновляться со старых сборок YaPlay без потери токена и локального кэша.

## Что уже работает

- Вход в Яндекс через device login или ручной OAuth-токен.
- Самостоятельный Android-плеер с MediaSession/MediaBrowser для системных
  медиакнопок, уведомления и автомобильных лаунчеров.
- Главный экран плеера с обложкой, названием трека, альбомом, исполнителем,
  кнопками лайка/дизлайка и крупными кнопками управления.
- "Моя волна" через rotor API Яндекс Музыки: сессия радио, feedback-события,
  быстрый старт с первого трека и дозагрузка только следующего трека вместо
  больших пачек.
- Отдельная полноэкранная "Волна клипов" из Android TV API: динамическая
  видеоочередь, адаптивные HLS/DASH-потоки, фоновая подготовка только одного
  следующего клипа, история назад и автоисчезающий оверлей с названием,
  исполнителем и крупными кнопками управления.
- Лайк клипа применяется к связанному треку в глобальном разделе "Мне
  нравится" и использует существующую настройку автоматического скачивания
  понравившихся треков в постоянный аудиокэш.
- Оффлайн-режим из постоянного кэша понравившихся треков Яндекс Музыки.
- Постоянное хранение только глобального раздела "Мне нравится"; нелайкнутые
  треки используют только ограниченный временный кэш воспроизведения.
- Раздельный выбор качества для онлайн-воспроизведения и постоянного кэша
  избранных треков в отдельном верхнем разделе настроек: авто/максимум,
  эконом 128, стандарт 192, высокое 320.
- Синхронизация избранного в локальный кэш с опциями "только Wi-Fi" и "только
  на зарядке".
- Кнопка очистки локального кэша.
- Поиск по Яндекс Музыке с мини-обложками, воспроизведением найденных треков,
  альбомов и популярных треков артиста, а также добавлением найденного трека в
  плейлист Яндекс Музыки.
- Работа с плейлистами аккаунта Яндекс Музыки: выбор, воспроизведение,
  добавление текущего трека, создание нового плейлиста и удаление с
  подтверждением.
- Локальные плейлисты приложения: добавление файлов и папок через собственный
  браузер YMPlayer с чекбоксами. Для нового хранилища или USB Android всё равно
  один раз показывает системный SAF-диалог, чтобы выдать приложению доступ.
- Управление локальными плейлистами: переименование, просмотр треков, удаление
  отдельных треков и обновление ранее импортированных папок.
- Неудаляемый локальный плейлист "Локальное избранное" для лайкнутых локальных
  файлов.
- Корректный пропуск недоступных локальных файлов, например если USB-накопитель
  не подключён.
- Поиск и запись обложек в локальные файлы, если в самом файле нет встроенной
  обложки и провайдер хранилища разрешает запись.
- Передача bitmap-обложек в MediaSession и уведомление, чтобы CarWebGuru и
  похожие лаунчеры могли показывать обложку.
- Если у трека нет доступной обложки или загрузка сорвалась, MediaSession,
  уведомление и главный экран получают стандартную обложку YMPlayer, а не
  оставляют картинку предыдущего трека.
- Главный экран, уведомление и MediaSession используют общий дисковый кэш
  обложек и повторяют загрузку после кратковременного сбоя сети/хранилища,
  что снижает риск увидеть лого YMPlayer вместо реальной обложки после сна
  магнитолы.
- Кнопка EQ/DSP с выбором найденного приложения эквалайзера.
- Встроенный SideBar-оверлей для TS18: включается в настройках, показывается и
  скрывается с главного экрана.
- Кнопка сна встроенного SideBar отправляет штатную команду TS18/NWD
  `ACTION_KEY_VALUE` с `extra_key_value=0`: она гасит экран и переводит
  магнитолу в сон. Для перезагрузки оставлена отдельная кнопка с подтвержденным
  TS18 reboot UI.
- TS18-совместимые команды громкости/mute через NWD broadcasts с Android
  AudioManager fallback на обычных устройствах.
- Диагностика внутри приложения с копированием лога для тестирования на
  реальном устройстве.
- Ярлыки системных настроек энергосбережения и автозапуска.

## Как пользоваться

1. Установить APK из раздела [Скачать](#скачать) на устройство с Android 10 или
   новее.
2. Открыть YMPlayer и войти в Яндекс.
3. В настройках включить автоматическое скачивание понравившихся треков или
   вручную запустить синхронизацию избранного.
4. На главном экране выбрать "Моя волна", "Режим оффлайн" или нужный плейлист.
   Сам выбор режима не запускает воспроизведение автоматически.
5. Нажать Play для старта.
6. Для видео нажать "Волна клипов". Обычное аудио остановится, а полноэкранная
   динамическая очередь клипов запустится сразу; тап по видео показывает или
   скрывает оверлей управления.
7. В CarWebGuru выбрать YMPlayer как медиаплеер, если лаунчер показывает список
   доступных медиаприложений.

## Модель кэша

Постоянный оффлайн-кэш предназначен только для глобального раздела Яндекс
Музыки "Мне нравится". Не важно, где был поставлен лайк: в "Моей волне", поиске,
альбоме или плейлисте. Для приложения это один общий список избранных треков.

Если лайк снят, трек удаляется из постоянного кэша. Дизлайк отправляет
отрицательный feedback в Яндекс, удаляет трек из избранного при необходимости и
чистит его локальные аудиофайлы.

Треки без лайка могут временно попадать в отдельный ограниченный кэш для
онлайн-воспроизведения и экономии трафика, но не считаются пользовательским
оффлайн-хранилищем.

Файлы, скачанные официальным приложением Яндекс Музыки, напрямую не
используются: на Android 10+ они находятся в песочнице официального приложения и
могут быть зашифрованы или преобразованы.

## Моя волна

"Моя волна" не является конечным плейлистом. YMPlayer открывает radio/rotor
сессию, получает стартовую очередь, отправляет `radioStarted` и `trackStarted`,
предзагружает следующий трек и запрашивает продолжение очереди ближе к концу.
Если API неожиданно возвращает пустое продолжение, приложение открывает новую
сессию "Моей волны", а не считает список законченным.

Случайный порядок для "Моей волны" отключён намеренно: порядок формирует сам
радио-алгоритм Яндекс Музыки.

## Волна клипов

Раздел использует отдельный видеоротор, найденный в Android TV-клиенте
Кинопоиска: `rotor/combined/session`. Для каждого клипа YMPlayer получает
`playerId`, затем запрашивает VH-манифест с параметрами Android TV Яндекс
Музыки и передает доступный HLS/DASH-поток Media3.

В памяти удерживаются только текущий и следующий клип. После перехода следующий
элемент снова загружается в фоне, а при пустом продолжении открывается новая
динамическая сессия. Кнопка назад использует локальную историю уже показанных
клипов. Видео не сохраняется в постоянный кэш.

YMPlayer не обходит DRM. Если полный поток защищён, используется официальное
`previewUrl`, когда оно есть; иначе клип пропускается. Доступность раздела и
полных потоков может зависеть от аккаунта, подписки, региона и текущего
поведения неофициального API, поэтому первый запуск 0.5.x нужно проверить на
реальном устройстве по встроенной диагностике.

## Встроенный SideBar

Встроенный SideBar включается в настройках приложения. Для работы оверлея Android
попросит разрешение "поверх других окон". Панель переносит TS18-подход из
отдельного проекта SideBar: раскрытие вытягиванием от края, громкость, mute,
home, back и скрытие панели. Размер кнопок в YMPlayer оставлен крупнее исходного
варианта.

Встроенный SideBar не использует AccessibilityService. Кнопка с иконкой луны
отправляет ту же команду сна, которая работала в исходном SideBar:
`com.nwd.action.ACTION_KEY_VALUE` с байтовым `extra_key_value=0`. После команды
панель сворачивается, а экран магнитолы гаснет. Попытки программного полного
выключения удалены из активного кода.

Для перезагрузки оставлена отдельная кнопка, которая использует подтвержденный
на TS18 путь: прямой запуск
`com.android.launcher/com.nwd.tools.reboot.RebootActivity` или
`com.nwd.toolallinone.app/com.nwd.tools.reboot.RebootActivity`, затем
launcher-запросы `ACTION_REQUEST_START_ACTIVITY`, `ACTION_START_ACTIVITY` и
`ACTION_START_NWD_ACTIVITY` с `extra_package_name`/`extra_class_name`.

Для громкости/mute на TS18 YMPlayer отправляет
`com.nwd.action.ACTION_KEY_VALUE` только с `extra_key_value` либо
`com.nwd.can.action.ACTION_PLATFORM_SEND_CAN_VOLUME`, если устройство
использует CAN-громкость. На обычных Android-устройствах громкость управляется
через стандартный `AudioManager`.

## Сборка из исходников

Нужен JDK 17 и Gradle wrapper из репозитория:

```powershell
$env:JAVA_HOME = Join-Path $env:USERPROFILE ".codex\toolchains\jdk-17"
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\gradlew.bat assembleDebug lintDebug --no-daemon
```

После локальной сборки APK будет лежать в:

```text
app/build/outputs/apk/debug/YMPlayer-v0.5.1-debug-b61.apk
```

Этот путь относится только к локальной машине разработчика. На GitHub готовые
APK хранятся в `releases/<version>/` и прикрепляются к GitHub Release.
