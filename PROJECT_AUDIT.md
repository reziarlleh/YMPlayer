# Текущее состояние YMPlayer

Актуализировано для **1.1.0 / build 114**, 2026-09-08. Это текущий технический
срез, а не перечень всех когда-либо найденных ошибок. Предыдущие записи
сохранены в [историческом архиве](docs/history/PROJECT_AUDIT_before_1.1.0.md).

## Реализовано

- Самостоятельный Android-плеер, API 29+, MediaSession/MediaBrowserService,
  уведомление и передача метаданных с обложкой в CarWebGuru.
- Динамическая аудиоволна с продолжением очереди и подготовкой следующего трека;
  выбор источника останавливает текущий, новый запускается по Play.
- Сохранение источника, последнего трека и позиции; локальное/онлайн-воспроизведение.
- Постоянное избранное Яндекса и ограниченный временный playback cache.
  Одна синхронизация проверяет и ремонтирует аудио и настоящую обложку отдельно.
- Раздельные профили качества для онлайн-потока и постоянного кэша.
- Яндекс-плейлисты аккаунта: список, воспроизведение, создание, добавление трека,
  удаление с подтверждением и сохранением списка при ошибке API.
- Локальные плейлисты: SAF-хранилища, браузер с чекбоксами, файлы/папки,
  обновление папок, переименование, удаление, локальное избранное. Недоступные
  файлы пропускаются; полностью недоступный список останавливает плеер.
- Поиск треков/альбомов/артистов, мини-обложки и действия над результатами.
- Полноэкранная Волна клипов, подготовка следующего, seek/время, лайк связанного
  трека. Постоянного статус-бара в видео нет; сообщения внутри скрываемых controls.
- Авто/сенсор/пульт, видимый фокус без увеличения кнопок, полноэкранные разделы
  настроек, Android TV banner, учёт системных панелей, выреза и клавиатуры.
- Двухстрочный статус на аудиоэкране, в библиотеке, поиске и настройках;
  по нажатию раскрывается полный текст с журналом до 45% доступной высоты.
  Чтение журнала фоновое, только при открытой панели; есть переносы и прокрутка.
- Экспорт диагностики в Downloads, окно о приложении с донатом, проверка
  обновлений и резервная загрузка APK с проверкой размера и SHA-256.
- Встроенный SideBar без Accessibility. Сон и отдельная подтверждаемая
  перезагрузка K4811/NWD; сворачивание всегда последним пунктом.

## Что подтверждено, а что нет

Пользователь подтвердил исправленную перезагрузку K4811 в beta.11, единую
синхронизацию beta.12 и в целом работоспособность beta.13. Его замечания по
компоновке и статусу в видео учтены в 1.1.0. Это не равно проверке всех
производителей ТВ, всех USB-провайдеров или всех сетевых отказов.

В репозитории **есть автотесты**: кэш/целостность, безопасный Binder-контракт
перезагрузки, жизненный цикл окна, адаптивная геометрия, отступы и статус-панель.
Используются JUnit, Robolectric на API 29/35 и Mockito. Проверки подставной
службы не перезагружают физическое устройство. CI пока отсутствует.

Снимки Robolectric подтверждают геометрию, но software-отрисовка некоторых
Button отличается от настоящего Android. Для визуальной проверки применяется
также обычный эмулятор Android 15; он не заменяет Android TV и пульт.
Итоги конкретного выпуска находятся в `releases/1.1.0/README.md`.

После обновления пользователю остаются физические проверки: компоновка K4811,
пульт ТВ с журналом, длительная волна, сон/пробуждение, CWG и обновление через
сеть устройства. Новый авторизованный сетевой прогон воспроизведения в рамках
UI-правок не выполнялся; проигрывающие сервисы не изменялись.

## Ограничения и реальные задачи

- Поиск сейчас запрашивает первую страницу. Любимые артисты, mood/seeded wave
  и подборки «Для вас» не реализованы; требуют отдельной проверки API.
- Старый аудиокэш без контрольной суммы проверяется разбором пакетов и
  длительностью. Это не доказывает отсутствие любого слышимого дефекта.
- Недоступная у источника обложка остаётся отсутствующей: логотип используется
  только для отображения. Синхронизация не может создать настоящую обложку из ничего.
- Изменение профиля качества само по себе не перекодирует скачанный файл.
  Явная массовая перезагрузка в новом качестве остаётся в плане.
- Есть крупные классы и операции на отдельных `Thread`. Нужны более единая
  отмена фоновых задач и тесты гонок, но наличие raw Thread не доказывает баг.
- Имена вроде `sidebar_watchdog` исторические. Переименование допускается
  только с сохранением ключей настроек или миграцией, не косметическим сбросом.
- Обновление проверяет размер/хэш из HTTPS-манифеста; независимой криптографической
  подписи самого манифеста пока нет. SHA-256 не заменяет доверие к источнику.
- Release APK неотладочный, но пока подписывается прежним ключом из debug
  signing configuration для совместимости обновлений. Смену ключа нельзя делать
  молча: она нарушит установку поверх существующего приложения.
- Доступность Яндекс API, потоков и CDN зависит от сервиса, аккаунта и сети.
  Стабильный выпуск не означает официальную поддержку стороннего API.

## Не менять без необходимости

Аудиоволну, feedback и подготовку следующего трека, сохранение позиции,
MediaSession/CWG, постоянные обложки избранного и удаление после снятия лайка.
Не менять рабочие команды/порядок SideBar в рамках визуальных доработок.
Магнитола пользователя **K4811**, не TS10/TS18; детали подтверждённого пути:
[K4811_REBOOT.md](docs/K4811_REBOOT.md).

Обновлённый порядок будущих работ и отдельно отложенная 2.0: [ROADMAP.md](ROADMAP.md).
