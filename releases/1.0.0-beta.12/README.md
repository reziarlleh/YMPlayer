# YMPlayer 1.0.0-beta.12

Одна кнопка **«Синхронизировать избранное»** вместо раздельной загрузки музыки
и обложек. За один проход проверяются обе части каждого избранного трека:

- Есть песня, но нет обложки: скачивается обложка.
- Есть обложка, но отсутствует или повреждена песня: восстанавливается музыка.
- Повреждена обложка: исправный аудиофайл не скачивается заново.
- Всё исправно: повторной загрузки файлов нет.
- При сетевой ошибке повторное нажатие докачивает оставшееся.

Старый кэш очищать не нужно. Первая проверка существующей большой коллекции
может занять больше времени: файлы проверяются и получают контрольные суммы.
Обложки сохраняются для офлайн-показа. Лого плеера остаётся только заглушкой
на экране, а не заменой отсутствующей обложки в хранилище.

SideBar не менялся; перезагрузка предыдущей beta.11 подтверждена пользователем.
