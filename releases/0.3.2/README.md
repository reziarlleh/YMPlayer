# YMPlayer 0.3.2

Working debug build archived for real-device testing.

- APK: `YMPlayer-v0.3.2-debug-b32.apk`
- Built from app version `0.3.2`, versionCode `32`.
- See `CHANGELOG.md` for user-facing changes.

Main focus:

- Local favorites playlist and local playlist delete/clear controls.
- Yandex Music playlist deletion with confirmation.
- Missing local files are skipped during playback.
- DSP app chooser instead of direct Android sound settings fallback.
- Built-in SideBar edge hotspot reduced to 5 px and swipe-only reveal.
