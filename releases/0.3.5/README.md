# YMPlayer 0.3.5

Рабочая debug-сборка для тестирования на реальном устройстве.

- APK в репозитории: `YMPlayer-v0.3.5-debug-b35.apk`
- APK в GitHub Release: https://github.com/reziarlleh/YMPlayer/releases/download/v0.3.5/YMPlayer-v0.3.5-debug-b35.apk
- Версия приложения: `0.3.5`
- `versionCode`: `35`
- Основной список изменений: `CHANGELOG.md`

Главный фокус версии:

- Вместо отдельных кнопок `Файлы` и `Папка` в локальных плейлистах теперь одна
  кнопка `Добавить`.
- Добавлен собственный браузер YMPlayer для сохранённых Android SAF-хранилищ.
- В браузере можно отмечать чекбоксами отдельные аудиофайлы и папки целиком.
- Первый доступ к новому хранилищу или USB всё ещё выдаётся через системный
  Android-диалог, потому что это требование Android 10+.
