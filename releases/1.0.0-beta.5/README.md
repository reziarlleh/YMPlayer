# YMPlayer 1.0.0-beta.5

Исправляющий beta-релиз для Android 10 и новее с нативным stateful-фоном
D-pad-фокуса.

- Белая рамка и осветление являются частью фонового Drawable элемента.
- Отрисовка не зависит от focus-listener, `foreground` или `ViewOverlay`.
- Динамические кнопки не теряют подсветку после изменения состояния и цвета.
- Размеры элементов при фокусе и нажатии не меняются.
