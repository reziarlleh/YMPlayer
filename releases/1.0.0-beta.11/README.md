# YMPlayer 1.0.0-beta.11

Исправления SideBar для магнитол K4811. Плеер и кэш не менялись.

- Новое окно подтверждения перезагрузки с подключением к системной службе.
- Отмена не выполняет действий; повторное нажатие не дублирует команду.
- Ошибки подключения и отсутствие ответа отображаются явно и сохраняются
  в диагностике. Есть отдельный запасной вызов штатного диалога.
- Убрано ошибочное обозначение TS18 в сообщениях интерфейса и README.
- Кнопка сна, размеры и порядок кнопок SideBar сохранены.

## Установка

[Скачать APK](YMPlayer-v1.0.0-beta.11-release-b111.apk).
Можно установить поверх предыдущего YMPlayer без удаления приложения.
Требуется Android 10 или новее.
