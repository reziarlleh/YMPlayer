# YMPlayer 0.3.4

Рабочая debug-сборка для тестирования на реальном устройстве.

- APK в репозитории: `YMPlayer-v0.3.4-debug-b34.apk`
- APK в GitHub Release: https://github.com/reziarlleh/YMPlayer/releases/download/v0.3.4/YMPlayer-v0.3.4-debug-b34.apk
- Версия приложения: `0.3.4`
- `versionCode`: `34`
- Основной список изменений: `CHANGELOG.md`

Главный фокус версии:

- Переименование локальных плейлистов.
- Просмотр треков внутри локального плейлиста.
- Удаление отдельных треков из локального плейлиста.
- Обновление ранее импортированных папок.
- Запоминание удалённых папочных треков, чтобы refresh не возвращал их обратно.
