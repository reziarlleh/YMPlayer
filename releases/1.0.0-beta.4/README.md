# YMPlayer 1.0.0-beta.4

Исправляющий beta-релиз для Android 10 и новее с единым отображением
D-pad-фокуса на всех экранах.

- Белая рамка и осветление рисуются поверх любого элемента через `ViewOverlay`.
- Кнопки принимают фокус после касания, мыши и переключения в touch-mode.
- Главный экран, библиотека, поиск, диалоги, настройки и Волна клипов
  автоматически проверяются на интерактивные элементы.
- Размеры элементов при фокусе и нажатии не меняются.
