# YMPlayer 1.0.0-beta.6

Исправляющий beta-релиз для Android 10 и новее с автономными обложками
офлайн-избранного.

- Добавлена отдельная синхронизация обложек уже скачанных понравившихся треков.
- Аудиофайлы во время этой операции не загружаются повторно.
- Постоянные обложки доступны без интернета и не зависят от временного кэша.
- Ограничения Wi-Fi и зарядки, фоновая работа и остановка синхронизации
  поддерживаются.
- Резервное изображение YMPlayer теперь имеет размер 1254×1254 px и четко
  передается в медиасессию и автомобильный лаунчер.
