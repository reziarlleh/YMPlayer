# YMPlayer 1.0.0-beta.9

Небольшой beta-релиз для Android 10 и новее.

- В окно «О программе» добавлен блок добровольной поддержки автора.
- QR-код можно отсканировать или выбрать с сенсорного экрана и ТВ-пульта.
- Кнопка «Поддержать автора» открывает Donate.Stream во внешнем браузере.
- В README проекта добавлены QR-код и прямая ссылка для поддержки.
