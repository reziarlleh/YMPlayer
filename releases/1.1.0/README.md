# YMPlayer 1.1.0

Стабильная версия без пометки beta.

[Скачать APK](YMPlayer-v1.1.0-release-b114.apk)

- Статус-бар раскрывается в полный статус и прокручиваемый журнал по нажатию,
  повторное нажатие сворачивает его. Высота ограничена 45% доступного экрана.
- Волна клипов снова полноэкранная, без постоянного статус-бара.
- Название, исполнитель и альбом выровнены в одну колонку; кнопки действий
  расположены отдельно. На больших горизонтальных экранах метаданные крупнее.
- Документация и план развития актуализированы. Аудиодвижок, кэш и SideBar сохранены.
- Android 10+, minSdk 29; versionCode 114, targetSdk 35, APK неотладочный.
- Обновление поверх прежней версии, без удаления приложения; подпись сохранена.

## Проверка выпуска

- 94 теста на API 29/35 прошли: кэш, перезагрузка, адаптивная геометрия,
  системные отступы, длинные названия, раскрытие/прокрутка журнала.
- Сборка release и lint без ошибок; 68 прежних предупреждений lint.
- На эмуляторе Android 15 проверены установка поверх beta.13, реальная
  отрисовка, первый тап, прокрутка и повторный тап статус-панели.

  воспроизведения остаётся за пользователем. Авторизованная сетевая проверка
  воспроизведения в рамках этого визуального выпуска не выполнялась.
