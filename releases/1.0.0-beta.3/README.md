# YMPlayer 1.0.0-beta.3

Beta-релиз для Android 10 и новее с уточнённым интерфейсом пульта,
Волны клипов и настроек.

- Фокус пульта больше не меняет размер элементов: используется белая рамка,
  мягкое осветление и более яркий отклик на нажатие.
- Панель Волны клипов скрывается через 5 секунд и по первому нажатию Back.
- Прогресс клипа расположен сверху на всю ширину панели, информация и кнопки
  управления находятся ниже.
- Настройки открываются на весь экран и разделены на отдельные категории.
