# YMPlayer 1.0.0-beta.2

Beta-релиз для Android 10 и новее с исправленной плиткой Android TV.

- Добавлена фирменная прямоугольная плитка YMPlayer формата 16:9.
- Добавлена штатная точка входа Android TV (`LEANBACK_LAUNCHER`).
- Сохранены исправления beta.1: предварительный код авторизации, управление
  пультом, защита системных панелей TV и визуальный статус настроек.
