# YMPlayer 0.3.6

Рабочая debug-сборка для тестирования на реальном устройстве.

- APK в репозитории: `YMPlayer-v0.3.6-debug-b36.apk`
- APK в GitHub Release: https://github.com/reziarlleh/YMPlayer/releases/download/v0.3.6/YMPlayer-v0.3.6-debug-b36.apk
- Версия приложения: `0.3.6`
- `versionCode`: `36`
- Основной список изменений: `CHANGELOG.md`

Главный фокус версии:

- Более красивая строка поиска в рамке с закруглёнными краями.
- Результаты поиска теперь выглядят как музыкальные карточки с мини-обложками.
- У треков появились действия `Играть` и `В плейлист`.
- У альбомов и артистов появились явные действия воспроизведения.
- Найденный трек можно добавить в существующий или новый плейлист Яндекс Музыки.
