# YMPlayer 0.4.0

Debug build for Android 10+ (`minSdk 29`), versionCode 40.

## What changed

- The app is promoted to the 0.4 line after the accumulated player, search,
  local playlist, My Wave, and cache-quality changes.
- Audio quality controls are now in a dedicated top-level settings section.
- Online playback quality and permanent liked-track cache quality use separate
  visible full-width buttons.
- The settings screen now explains that already downloaded cached files keep
  their existing quality until cache refresh.

## APK

The APK for this release is:

- `YMPlayer-v0.4.0-debug-b40.apk`
