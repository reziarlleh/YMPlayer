# YMPlayer 1.0.0-beta.8

Исправляющий beta-релиз для Android 10 и новее.

- «Моя волна» отбрасывает текущий трек из rotor-продолжения и добавляет только
  одну новую рекомендацию.
- Пустая, повторяющаяся или временно недоступная порция автоматически
  восстанавливается и запрашивается повторно.
- Ошибочный трек больше не останавливает динамическую волну целиком.
- Фоновая подготовка следующего трека синхронизирована с автоматическим
  переходом по окончании текущего.
- Добавлены режимы управления «Авто», «Сенсор» и «Пульт».
- На обычном Android автоматический режим возвращает выполнение действий одним
  касанием, а на Android TV сохраняет D-pad-фокус и белую подсветку.
